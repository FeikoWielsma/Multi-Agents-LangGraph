# MM-09 error codes

- Document : MAN-MM-09-02
- Model : MM-09
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| F-MM-100 | ramp motor stall | run the ramp test in the workshop ; replace the motor if it stalls twice |
| F-MM-210 | ramp stops on battery power | replace the auxiliary battery |
| F-MM-320 | passenger cabin temperature warning | clean or replace the HVAC filter |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

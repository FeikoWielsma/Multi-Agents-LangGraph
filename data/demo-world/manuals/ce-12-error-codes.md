# CE-12 error codes

- Document : MAN-CE-12-02
- Model : CE-12
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| F-CE-110 | traction system over-temperature | check the traction cooling fan ; replace it if airflow is below 80 percent |
| F-CE-220 | traction battery insulation fault | isolate the traction battery ; replace the module after the workshop insulation test confirms a fault |
| F-CE-305 | door actuator communication loss | inspect and replace the door actuator |
| F-CE-410 | inverter communication dropout | run inverter calibration ; replace the module if dropout persists |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

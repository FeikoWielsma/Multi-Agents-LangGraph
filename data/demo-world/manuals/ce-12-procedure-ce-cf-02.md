# Replacing the traction cooling fan on the CE-12

- Document : PROC-CE-CF-02
- Model : CE-12
- Type : procedure
- Date : 2024-08-19

## When

Error F-CE-110, traction system over-temperature. First action : check the traction cooling fan ; replace it if airflow is below 80 percent.

## Part

- Part number CE-CF-02, traction cooling fan
- Check stock in the parts system before travelling

## Steps

1. Book a workshop bay and isolate the bus under the depot procedure
2. Follow the workshop isolation check before removing the component cover
3. Disconnect and remove the old traction cooling fan
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and fleet_no on the work order

## Time

Allow 2 hours in the workshop.

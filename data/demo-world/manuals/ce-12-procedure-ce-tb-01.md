# Replacing the traction battery module on the CE-12

- Document : PROC-CE-TB-01
- Model : CE-12
- Type : procedure
- Date : 2024-08-19

## When

Error F-CE-220, traction battery insulation fault. First action : isolate the traction battery ; replace the module after the workshop insulation test confirms a fault.

## Part

- Part number CE-TB-01, traction battery module
- Check stock in the parts system before travelling

## Steps

1. Book a workshop bay and isolate the bus under the depot procedure
2. Follow the workshop isolation check before removing the component cover
3. Disconnect and remove the old traction battery module
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and fleet_no on the work order

## Time

Allow 6 hours in the workshop.

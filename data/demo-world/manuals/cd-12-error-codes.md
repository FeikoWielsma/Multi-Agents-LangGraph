# CD-12 error codes

- Document : MAN-CD-12-02
- Model : CD-12
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| F-CD-101 | engine intake pressure low | replace the engine air filter and check intake pressure after the workshop test cycle |
| F-CD-202 | fuel pump pressure low | withdraw the bus from service ; call the diesel specialist ; fuel pump replacement needs a workshop bay |
| F-CD-330 | engine control fault | run the controller check ; replace the engine control unit if the check fails twice |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

# RR-14 error codes

- Document : MAN-RR-14-02
- Model : RR-14
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| F-RR-120 | door controller not responding | charge or replace the auxiliary battery pack |
| F-RR-240 | step light failure | replace the step light |
| F-RR-350 | door position out of range | run the door position calibration ; replace the door controller if it fails |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

# Replacing the detector battery pack on the DR-60

- Document : PROC-DR-BP-03
- Model : DR-60
- Type : procedure
- Date : 2024-08-19

## When

Error E-DR-120, detector not responding. First action : charge or replace the detector battery pack.

## Part

- Part number DR-BP-03, detector battery pack
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old detector battery pack
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 2 hours on site.

# Replacing the helium compressor filter on the MR-150

- Document : PROC-MR-HF-01
- Model : MR-150
- Type : procedure
- Date : 2024-08-19

## When

Error E-MR-101, helium compressor pressure low. First action : replace the helium compressor filter and check the pressure after 30 minutes.

## Part

- Part number MR-HF-01, helium compressor filter
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old helium compressor filter
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 2 hours on site.

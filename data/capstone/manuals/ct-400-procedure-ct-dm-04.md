# Replacing the detector module on the CT-400

- Document : PROC-CT-DM-04
- Model : CT-400
- Type : procedure
- Date : 2024-08-19

## When

Error E-CT-410, detector channel dropout. First action : run detector calibration ; replace the module if dropout persists.

## Part

- Part number CT-DM-04, detector module
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 30 minutes for the gantry to cool
2. Remove the service cover marked with the part number
3. Disconnect and remove the old detector module
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 6 hours on site.

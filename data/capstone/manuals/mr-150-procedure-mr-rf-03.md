# Replacing the RF body coil on the MR-150

- Document : PROC-MR-RF-03
- Model : MR-150
- Type : procedure
- Date : 2024-08-19

## When

Error E-MR-330, RF coil fault. First action : run the coil check ; replace the RF body coil if the check fails twice.

## Part

- Part number MR-RF-03, RF body coil
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old RF body coil
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 6 hours on site.

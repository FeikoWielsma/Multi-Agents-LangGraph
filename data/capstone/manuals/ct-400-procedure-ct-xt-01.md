# Replacing the X-ray tube assembly on the CT-400

- Document : PROC-CT-XT-01
- Model : CT-400
- Type : procedure
- Date : 2024-08-19

## When

Error E-CT-220, tube arcing detected. First action : run the tube seasoning routine ; replace the tube assembly after three arcing events in 24 hours.

## Part

- Part number CT-XT-01, X-ray tube assembly
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 30 minutes for the gantry to cool
2. Remove the service cover marked with the part number
3. Disconnect and remove the old X-ray tube assembly
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 6 hours on site.

# Replacing the linear transducer L12 on the UX-20

- Document : PROC-UX-TL-01
- Model : UX-20
- Type : procedure
- Date : 2024-08-19

## When

Error E-UX-100, transducer element failure. First action : run the transducer test ; replace the transducer if more than two elements fail.

## Part

- Part number UX-TL-01, linear transducer L12
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old linear transducer L12
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 6 hours on site.

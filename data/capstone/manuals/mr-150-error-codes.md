# MR-150 error codes

- Document : MAN-MR-150-02
- Model : MR-150
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| E-MR-101 | helium compressor pressure low | replace the helium compressor filter and check the pressure after 30 minutes |
| E-MR-202 | cold head temperature high | stop scanning ; call the MR specialist ; cold head replacement needs a planned ramp-down |
| E-MR-330 | RF coil fault | run the coil check ; replace the RF body coil if the check fails twice |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

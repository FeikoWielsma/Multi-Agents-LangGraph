# DR-60 error codes

- Document : MAN-DR-60-02
- Model : DR-60
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| E-DR-120 | detector not responding | charge or replace the detector battery pack |
| E-DR-240 | collimator light failure | replace the collimator lamp |
| E-DR-350 | image uniformity out of range | run the gain calibration ; replace the flat panel detector if it fails |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

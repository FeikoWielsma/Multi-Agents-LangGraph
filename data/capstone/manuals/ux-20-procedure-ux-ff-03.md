# Replacing the fan filter on the UX-20

- Document : PROC-UX-FF-03
- Model : UX-20
- Type : procedure
- Date : 2024-08-19

## When

Error E-UX-320, internal temperature warning. First action : clean or replace the fan filter.

## Part

- Part number UX-FF-03, fan filter
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old fan filter
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 2 hours on site.

# Replacing the flat panel detector on the DR-60

- Document : PROC-DR-FP-01
- Model : DR-60
- Type : procedure
- Date : 2024-08-19

## When

Error E-DR-350, image uniformity out of range. First action : run the gain calibration ; replace the flat panel detector if it fails.

## Part

- Part number DR-FP-01, flat panel detector
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old flat panel detector
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 6 hours on site.

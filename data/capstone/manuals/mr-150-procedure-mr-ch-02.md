# Replacing the cold head on the MR-150

- Document : PROC-MR-CH-02
- Model : MR-150
- Type : procedure
- Date : 2024-08-19

## When

Error E-MR-202, cold head temperature high. First action : stop scanning ; call the MR specialist ; cold head replacement needs a planned ramp-down.

## Part

- Part number MR-CH-02, cold head
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 10 minutes
2. Remove the service cover marked with the part number
3. Disconnect and remove the old cold head
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 6 hours on site.

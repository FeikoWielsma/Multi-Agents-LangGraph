# UX-20 error codes

- Document : MAN-UX-20-02
- Model : UX-20
- Type : manual
- Date : 2024-05-02

## Error code reference

| Code | Meaning | First action |
| --- | --- | --- |
| E-UX-100 | transducer element failure | run the transducer test ; replace the transducer if more than two elements fail |
| E-UX-210 | system shuts down on battery | replace the system battery |
| E-UX-320 | internal temperature warning | clean or replace the fan filter |

## General rule

Clear an error only after the cause is fixed. An error that returns within 24 hours
is escalated to second line with the full system log attached.

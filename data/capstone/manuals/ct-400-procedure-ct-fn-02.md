# Replacing the gantry cooling fan on the CT-400

- Document : PROC-CT-FN-02
- Model : CT-400
- Type : procedure
- Date : 2024-08-19

## When

Error E-CT-110, gantry over-temperature. First action : check the gantry cooling fan ; replace it if airflow is below 80 percent.

## Part

- Part number CT-FN-02, gantry cooling fan
- Check stock in the parts system before travelling

## Steps

1. Lock out the system and wait 30 minutes for the gantry to cool
2. Remove the service cover marked with the part number
3. Disconnect and remove the old gantry cooling fan
4. Fit the new part and reconnect
5. Run the self test ; the error must not return
6. Record the part number and serial on the work order

## Time

Allow 2 hours on site.
